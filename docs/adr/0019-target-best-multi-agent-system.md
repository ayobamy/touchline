# ADR 0019: Target the Best Multi-Agent System category

- **Status:** Accepted
- **Date:** 2026-10-15

## Context

A project can win one grand prize and at most one category prize, and "adherence to hackathon category" is 20% of the score. The categories are Best Use of Microsoft Foundry, Best Enterprise Solution, Best Multi-Agent System and Best Azure Cloud Native Integration.

## Decision

Aim at Best Multi-Agent System, while still competing for the grand prizes.

## Consequences

- Design choices favour visible agent behaviour: distinct roles, shared state, explicit handoffs, recovery from failure, and an agent-trace panel in the viewer and the video.
- Foundry and Azure services are still used properly, which also helps the grand-prize score.
